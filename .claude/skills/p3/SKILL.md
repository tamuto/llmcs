# p3 でこのプロジェクトの作業を管理する（入口）

このリポジトリの作業は、infodb p3 の **要望** と、要望から生まれた **タスク** で管理する。
作業の手順の本文はこのファイルには無く、動いている p3 の CLI が返す（CLI が新しくなれば手順も新しくなる）。

1. p3 を操作する前に `pnpx @infodb/p3 guide --json` を実行し、返った JSON の `guide`（作業の手順）を最後まで読んで、その手順に従う。
   手順の中の `p3 <コマンド>` も、同じ呼び方（`pnpx @infodb/p3`）で呼ぶ
2. `guide` を取得できなければ（コマンドが無い・エラーになる・JSON が読めない）、p3 を操作しない。出たエラーと
   呼び方（`pnpx @infodb/p3 guide --json`）を人に伝えて終える
3. 手順をこのファイルや AGENTS.md に写さない。このファイルを自分で書き換えない（更新は人が `p3 agents` で行う）
